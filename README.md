# Blue Day — персональный рабочий стол
Автор: Ксения Филиппова

Приложение на чистом JavaScript, ES6 Modules, HTML и CSS Grid. Без сборщика и зависимостей.

## Запуск
Запустите `python3 -m http.server 8080 --directory dist` и откройте http://localhost:8080. Не открывайте index.html через file://: модулям нужен HTTP-сервер.

## Структура
- dist/index.html — страница и подключение main.js с type="module".
- dist/main.js — создание Dashboard, управление меню добавления.
- dist/js/UIComponent.js — абстрактный базовый класс, render, minimize, close, destroy, регистрация слушателей и отмена запросов.
- dist/js/Dashboard.js — приватная коллекция виджетов, addWidget(widgetType), removeWidget(widgetId), реестр классов и сохранение раскладки.
- dist/js/ToDoWidget.js — приватный массив задач, добавление, удаление, выполнение и прогресс.
- dist/js/NotesWidget.js — приватное состояние заметок и localStorage.
- dist/js/ClockWidget.js — часы/дата Москвы, таймер очищается при удалении.
- dist/js/WeatherWidget.js — запрос к Open-Meteo, выбор одного из трёх городов.
- dist/js/QuoteWidget.js — запрос к https://api.quotable.io/random и обновление цитаты.
- dist/js/storage.js — безопасное чтение/запись localStorage.
- dist/styles/main.css — общая сетка и адаптивность.
- dist/styles/components.css — стили виджетов.

## ООП
Наследование: пять виджетов расширяют UIComponent. Полиморфизм: Dashboard вызывает render/destroy/serialize одинаково для разных классов. Инкапсуляция: #widgets, #tasks, #text, #timer и другие приватные поля. Чтобы зарегистрировать новый класс, вызовите dashboard.register('type', Class); алгоритм addWidget не меняется.

Состояния экземпляров независимы: задачи и заметки сохраняются под ключами с уникальными ID. Список виджетов и свёрнутость сохраняются. При закрытии виджета снимаются слушатели, отменяются fetch, очищается таймер часов. Сохранённые задачи и заметки не стираются при закрытии; новый экземпляр получает новый ID.

## API и ограничения
Погода: https://open-meteo.com/, текущие данные и суточные максимум/минимум. Цитаты: Quotable, оригинал на английском. Два класса выполняют реальные fetch, без ключей. При недоступности Quotable явно показывается локальная резервная цитата; это не ответ API. При ошибке погоды данные не выдумываются, отображается ошибка с повторной загрузкой. Запросы имеют таймаут 10 секунд. Доступность сторонних сервисов и CORS зависят от провайдеров.

Данные сохраняются только в браузере на данном домене; синхронизации между устройствами нет. Интерфейс адаптивен, элементы имеют подписи и клавиатурный фокус, меню закрывается Escape. Необязательное перетаскивание не реализовано.

## Проверка вручную
Добавьте два списка дел и убедитесь, что задачи независимы. Добавьте, выполните и удалите задачу. Напишите заметку и перезагрузите страницу. Сверните/разверните и удалите виджет. Проверьте API, обновление цитат, ошибки при отключении сети и мобильную ширину.
